#### How to Run

**Linux / macOS**
1. Open your terminal and navigate to the folder containing the file.
2. Ensure the file has execution permissions:
```bash
chmod +x tomo-paint-converter
```
3. Run the application:
```bash
./tomo-paint-converter
```

**Windows**
1. Run the application by double-clicking `tomo-paint-converter.exe` or via PowerShell:
```powershell
.\tomo-paint-converter.exe
```
